# Password Strength Analyzer

An interactive web application to check and enhance the strength of user-generated passwords.

## Features

- ✅ Real-time password strength analysis
- ✅ Visual strength meter with color-coded feedback
- ✅ Checks for:
  - Password length (minimum 8 characters, recommended 12+)
  - Uppercase letters (A-Z)
  - Lowercase letters (a-z)
  - Numbers (0-9)
  - Special characters (!@#$%^&*()_+-=[]{}|;:,.<>?)
- ✅ **Strong password generator** with customizable options:
  - Adjustable length (8-32 characters)
  - Toggle uppercase, lowercase, numbers, and special characters
  - Cryptographically secure random generation
  - One-click copy to clipboard
- ✅ Detailed feedback for improving weak passwords
- ✅ Security tips and best practices
- ✅ Password visibility toggle
- ✅ Responsive design for mobile and desktop
- ✅ Generated passwords are secure and random

## How to Run

Simply open `index.html` in your web browser by double-clicking the file.

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and responsive design
- `script.js` - Password analysis logic and UI interactions

## Security Notes

- This tool runs entirely in the browser - no passwords are sent to any server
- All analysis is performed client-side using JavaScript
- Your passwords remain private and secure
